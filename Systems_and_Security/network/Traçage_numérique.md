# Traçage numérique

Sources : [[Polytech/S6/CN/Cours|Cours CN]]

Ce qui nous **trace** sur internet :
- **Cookies**
- **Fingerprints** (empreinte navigateur) → https://amiunique.org/fingerprint
- Réseaux sociaux (LinkedIn, Instagram, TikTok…)
- **OS du téléphone**
- **@IP publique** => adresse *logique*
- **@MAC** => *unique*, liée au matériel — 6 octets, les 3 premiers = constructeur. Voir [[MAC address]].
- Opérateur télécom
- HTTP → IP/TCP : permet de connaître l'OS du PC, sans naviguer
